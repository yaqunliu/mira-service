# 视频分镜提示词模板 (V6 专业版 · 三维度知识库)

## 核心理念

基于 video_generation_v6.md 的专业电影级提示词生成规范，本知识库提供完整的分镜案例参考。

**V6 核心特点：**
1. **三维度分离**：画面 + 背景音 + 人物对白独立设计
2. **时间轴驱动**：精确到 0.1 秒的时间标注
3. **简洁表达**：只写动作/状态，拒绝修饰词和情绪解释
4. **首尾帧驱动**：从首帧开始，到尾帧定格
5. **多镜头切换**：单镜头 1.5-2.5 秒，频繁切换增强节奏

## 基础结构（V6 简洁版格式）

```
[全局氛围]：一句话描述色调、光影、风格。

---

[0-Xs] 镜头1
画面：[0-Xs] 景别+运镜。动作/状态。
背景音：环境音；音效；音乐
人物对白：（无）或 [Xs-Ys] 角色+语气："台词"

[X-Ys] 镜头2
画面：[X-Ys] 景别+运镜。cut。动作/状态。
背景音：环境音持续；音效；音乐变化
人物对白：[Xs-Ys] 角色+语气："台词"

[Y-Zs] 镜头N（尾帧）
画面：[Y-Zs] 景别+运镜。定格。
背景音：环境音渐弱；音效；音乐骤停
人物对白：（无）
```

## 详细分镜格式（复杂场景专用）

```
分镜标题（可选）
画面：[时间段] 景别+角度。详细动作。cut [时间段] 镜头切换。
背景音：[时间段] 环境音。[时间段] 音效描述。
对白：[时间段] 角色："完整台词"
```
