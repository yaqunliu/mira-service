# 角色特征提取（全身动画风格版本）

## 任务
从输入文案中提取完整角色特征库，包含“角色名-状态”（如有）。输出用于后续角色与分镜生成。

## 规则
- 人物名称必须写全：“角色名-状态”若有状态（如“陶未-青年”）。
- 保留性格、情绪、外貌、身材、发型、服装、动作/姿态、标签等关键信息。
- 若文案未给出，标记为“未知”但不要捏造。

## 输出格式（JSON）
```
{
  "characters": [
    {
      "name": "角色名-状态",
      "basic_info": "...",
      "appearance": "...",
      "body_shape": "...",
      "hair": "...",
      "clothes": "...",
      "action_pose": "...",
      "tags": ["..."],
      "notes": "..."
    }
  ]
}
```

## 输入示例
```
[场景正文]
```

## 重要
- 不编造文案不存在的细节；缺失用“未知”。
- 输出只包含 JSON，不要多余说明。
