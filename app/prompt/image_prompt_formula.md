# 万能出图公式

## 核心公式

**主体 + 场景 + 风格 + 色彩 + 构图 + 细节**

---

## 六大要素详解

### 1. 主体内容

描述画面中的核心对象，需要具体、生动、有辨识度。

| 类型 | 描述要点 | 示例 |
|-----|---------|-----|
| **人物** | 职业、年龄、外貌特征、服装、动作、表情 | 一位戴着眼镜的年轻女画家，穿着沾满颜料的围裙 |
| **动物** | 物种、毛色、大小、姿态、特征 | 一只金色毛发的柴犬，歪着头好奇地看向镜头 |
| **物品** | 类型、材质、状态、用途 | 一把锈迹斑斑的古董钥匙，上面缠绕着枯萎的藤蔓 |
| **概念** | 抽象概念的具象化表达 | "孤独"、"丰收"、"宁静"、"希望" |

**人物描写公式**：
```
[性别][年龄段][职业/身份] + [外貌特征] + [服装描述] + [动作/姿态] + [表情/情绪]
```

---

### 2. 场景设定

描述画面发生的时空背景，营造氛围感。

| 维度 | 选项 | 说明 |
|-----|-----|-----|
| **空间** | 室内、室外、幻想空间 | 具体场所：咖啡厅、阁楼画室、未来都市、魔法森林 |
| **时间** | 清晨、正午、黄昏、午夜、黎明 | 影响光线方向和色调 |
| **天气** | 晴天、雨天、雪天、暴风雪、雾天、星空 | 增加氛围层次 |
| **环境** | 周围参照物、整体氛围 | 背景元素、环境道具、空间层次 |

**场景描写公式**：
```
[时间段] + [天气状态] + [具体地点] + [环境细节] + [氛围描述]
```

| 浮世绘风格 | 平面感、线条感、东方美学 |
| 蒙德里安风格 | 几何色块、极简主义 |

#### 动画电影风格

| 复古暖黄调 | 温暖、怀旧、胶片感 | 回忆、温馨场景 |
| 冷色调蓝紫 | 冷峻、神秘、孤独感 | 悬疑、忧郁场景 |

#### 光线感
| 光线类型 | 效果 |
|---------|-----|
| 柔和侧光 | 温柔、自然、立体感 |
| 电影感逆光 | 轮廓光、氛围感、戏剧性 |
| 顶光 | 神圣感、舞台感 |
| 底光 | 恐怖感、神秘感 |
| 伦勃朗光 | 经典人像、明暗对比 |
| 环境光 | 自然、真实、沉浸感 |

#### 色彩关系
| 类型 | 效果 |
|-----|-----|
| 高饱和度撞色 | 强烈视觉冲击、活力感 |
| 和谐邻近色 | 统一、舒适、协调 |

| 单色调 | 纯粹、专注、艺术感 |

### 5. 构图视角

定义画面的空间布局和观看角度。

#### 景别
| 景别 | 画面范围 | 用途 |
|-----|---------|-----|
| 极近特写 | 面部局部（眼睛、嘴唇） | 情感表达、细节刻画 |
| 特写 | 面部或物品 | 情绪传达、聚焦注意力 |
| 中近景 | 胸部以上 | 人物表情、对话场景 |
| 中景 | 腰部以上 | 人物互动、肢体动作 |
| 全景 | 人物全身 | 人物与环境关系 |
| 远景 | 人物在环境中 | 场景建立、氛围渲染 |

#### 镜头视角
| 镜头类型 | 效果 |
|---------|-----|
| 微距镜头 | 拍摄微小物体，展现细节 |
| 超广角镜头 | 能拍摄广阔场景，空间感强 |
| 长焦镜头 | 远距离拍摄，压缩空间，背景虚化 |
| 鱼眼镜头 | 产生夸张变形效果，冲击力强 |
| 标准镜头 | 接近人眼视角，自然真实 |

#### 观察视角
| 视角 | 效果 | 适用场景 |
|-----|-----|---------|
| 仰视视角 | 从下往上看，突出主体高大 | 英雄、建筑、权威感 |
| 俯视视角 | 从上往下看，展示整体布局 | 全景、渺小感、上帝视角 |
| 平视视角 | 与人眼平行，给人自然感觉 | 日常、对话、亲切感 |
| 鸟瞰视角 | 从高空俯瞰，展现全貌 | 城市、战场、宏观场景 |
| 第一人称视角 | 让观众有身临其境之感 | 沉浸感、互动感 |
| 过肩视角 | 站在角色身后观看 | 悬疑、跟随感 |

#### 构图法则
| 构图方法 | 说明 |
|---------|-----|
| 黄金分割 | 将主体置于黄金分割点，美感平衡 |
| 三分构图 | 画面分为九宫格，主体放置在四个交叉点上 |
| 对称构图 | 画面左右或上下对称，具有稳定性 |
| 中心构图 | 主体位于画面中心，聚焦感强 |
| 引导线构图 | 利用线条引导视线到主体 |
| 对角线构图 | 主体沿对角线分布，动感十足 |
| 框架构图 | 用前景元素框住主体，层次感强 |

#### 特色构图
| 构图方法 | 说明 |
|---------|-----|
| 3D平面图 | 展现三维空间中的平面布局 |
| 散点构图 | 画面元素分散分布 |
| 圆形构图 | 将主体置于圆形内 |
| Knolling | 将物体有序排列，整齐美学 |
| 等距视图 | 能同时展示物体多个面 |

### 6. 图片细节

提升画面质感和真实度的关键要素。

#### 画质参数
| 参数 | 效果 |
|-----|-----|
| 8K | 超高清分辨率 |
| 超精细细节 | 增加画面细节层次 |
| HDR | 高动态范围，光影层次丰富 |
| RAW质感 | 真实、未经处理的质感 |

#### 材质质感
| 材质 | 描述词 |
|-----|-------|
| 金属 | 冰冷反光、金属光泽、拉丝纹理 |
| 皮肤 | 皮肤纹理、毛孔细节、光滑质感 |
| 布料 | 褶皱、纤维纹理、垂坠感 |
| 玻璃 | 透明、反射、折射光线 |
| 木质 | 木纹、温润、自然质感 |
| 水面 | 波纹、反射、透明度 |

#### 光影特效
| 特效 | 效果 |
|-----|-----|
| 体积光 | 光束可见、神圣感、氛围感 |
| 镜头光晕 | 逆光时的光斑，电影感 |
| 丁达尔效应 | 光线穿透空气中的微粒 |
| 焦散 | 水面或玻璃的光线折射图案 |
| 景深/虚化 | 主体清晰、背景模糊 |
| 动态模糊 | 速度感、运动感 |

#### 画面尺寸
| 比例 | 适用场景 |
|-----|---------|
| 16:9 | 横版视频、宽屏电影 |
| 9:16 | 竖版视频、手机壁纸 |
| 4:3 | 传统照片、复古感 |
| 1:1 | 头像、社交媒体 |
| 21:9 | 超宽屏电影、史诗感 |

## 案例解析

### 案例1：画室女画家

**主体内容**：一位戴着眼镜的年轻女画家，穿着沾满颜料的围裙，正专注地在画架前调色。

**场景设定**：一个充满阳光的阁楼画室，背景是杂乱而有序的画具和几幅未完成的作品，光线透过窗户形成光束。

**风格**：电影感写实人像摄影，强调光影的故事感。

**色彩/色调**：复古暖黄调为主，营造一种温暖、安静的午后氛围。

**构图视角**：侧前方视角，采用黄金分割构图，人物位于画面右侧。

**图片细节**：空气中漂浮的微尘，画布的帆布纹理，颜料的粘稠质感，8K画质。

---

### 案例2：沙漠商队

**主体内容**：一位蒙着面纱的女商人，带领着一支满载香料和丝绸的骆驼商队。

**场景设定**：傍晚时分的金色沙漠，沙丘连绵起伏，天空中挂着一轮巨大的弯月。

**风格**：异域风情浓郁的古典油画风格，笔触厚重，色彩饱满。

**色彩/色调**：大面积的沙漠金色与被晚霞染成紫红色的天空形成和谐统一的暖色调。

**构图视角**：侧面跟随视角，展现商队行进的动态感，构图呈对角线延伸。

**图片细节**：骆驼身上华丽的挂毯和铃铛，风吹起商人面纱的一角，沙丘上被风吹出的细腻纹路。

---

### 案例3：赛博朋克侦探

**主体内容**：一名撑着透明发光雨伞的侦探，身穿风衣，站在巷口，身影被拉得很长。

**场景设定**：一座未来城市的雨夜小巷，地面湿滑，反射着两侧店铺的日文和英文霓虹灯牌。

**风格**：赛博朋克黑色电影风格，高对比度，氛围感强。

**色彩/色调**：以冷色调的蓝、紫为主，穿插着饱和度极高的粉、黄霓虹灯光。

**构图视角**：经典过肩视角，仿佛我们正站在他身后，一同望向巷子深处。

**图片细节**：雨水打在透明雨伞上的水珠，地面霓虹灯的倒影，远处空中飞车的模糊光影。

## 实战提示词示例库

### 人像写真类

**示例1：戏剧性人像**
```
银发中年男子，面无表情地看向镜头，手持一把大画笔贴近脸颊。直发，方脸，穿着黑色西装和白色衬衫，搭配领带。黑白半身照，背景纯黑，人物居中构图，光影效果突出面部和画笔的质感，长焦镜头拍摄，浅景深使人物更加立体，画面整体显得简洁有力，具有强烈的戏剧性和艺术感。
```

**示例2：北欧风人像**
```
高度写实的北欧女性肖像，金发碧眼，脸部雀斑清晰可见，眼神犀利而知性。光影要体现出北欧特有的清冷感，装扮简约现代，背景虚化成冷色调。需要完美表现出斯堪的纳维亚女性的特点。
```

**示例3：王家卫电影感**
```
照片，摄影人像，写实人像：背景是故宫红墙，女子身穿黑色旗袍，手握扇子，长曝光摄影，王家卫电影感，故事感，人来人往，迷离的光线，形成迷离的轨迹，柔焦摄影，眼神深邃神秘，艺术气息十足。
```

**示例4：伦勃朗光**
```
写实风格，伦勃朗光艺术效果，近景中心视角，中心构图，穿着素色裙女孩站屋外墙边头偏一侧，有藤蔓小花，暖黄调，中等饱和度、高对比度、适中明度，开场聚焦女孩脸部并增亮光线，过渡环绕展示光影，结尾稍拉镜头显全貌。
```

**示例1：韦斯·安德森风格对称构图**

```
一张韦斯·安德森风格的电影截图。一个复古酒店的大堂前台，所有元素都呈现出完美的左右对称构图。一个穿着制服的门童正站在正中央，背景的墙壁、挂画和灯具都严格对称，色彩是那种标志性的、饱和度不高的粉蜡色。
```
