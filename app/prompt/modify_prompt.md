# 提示词修改

## 任务说明

根据原提示词、修改类型和用户反馈，对提示词进行修改优化。这是一个**修改**任务，需要基于原提示词进行修改，保留核心要素，根据用户反馈进行针对性调整。

## 修改类型说明

| 修改类型 | 说明 | 操作要点 |
|---------|------|---------|
| **simplify** | 简化提示词 | 保留核心要素，去除冗余、重复的描述，使提示词更简洁明了 |
| **detail** | 添加细节 | 在保留原提示词的基础上，添加更多细节描述，丰富画面内容 |
| **fix** | 修正错误 | 识别并修正原提示词中的错误或不准确之处，保持其他正确内容不变 |
| **style** | 改变风格 | 调整风格描述，改变视觉调性，保留主体内容，改变表现方式 |
| **custom** | 自定义修改 | 根据用户具体反馈进行修改，保留原提示词中不需要修改的部分 |

## 修改规则

### 1. simplify（简化）

**目标**：去除冗余，保留核心

**操作要点**：
- 保留原提示词的核心要素和关键约束
- 去除冗余、重复的描述
- 去除不必要的修饰词
- 使提示词更简洁明了，但不丢失重要信息

**示例**：
```
原提示词：她优雅地抬起纤细的手指，轻轻拨弄着柔顺的发丝，眼神中流露出淡淡的忧伤，站在窗边望着远方
简化后：她抬手拨弄头发，眼神低垂，站在窗边
```

### 2. detail（加细节）

**目标**：丰富内容，增强表现力

**操作要点**：
- 在保留原提示词的基础上
- 添加更多细节描述（服装纹理、环境元素、光影变化等）
- 增强视觉表现力和层次感
- 不要改变原有的核心内容

**示例**：
```
原提示词：她站在窗边，穿着白色连衣裙
加细节后：她站在窗边，阳光透过纱帘洒在身上，穿着白色蕾丝连衣裙，裙摆随风轻轻飘动，腰间系着细细的丝带
```

### 3. fix（修正）

**目标**：纠正错误，确保准确

**操作要点**：
- 识别并修正原提示词中的错误或不准确之处
- 保持其他正确内容不变
- 确保描述准确、符合资源信息
- 如果用户指出了具体问题，优先修正这些问题
- **重要**：直接给出修正后的描述，不要提及"不再"、"改为"、"从...变成..."等变化过程

**示例**：
```
原提示词：他穿着蓝色校服，站在操场上
用户反馈：应该是红色校服，在教室里
修正后：他穿着红色校服，站在教室里
```

**错误示例**（不要这样输出）：
```
他不再穿蓝色校服，改为穿红色校服，从操场改为站在教室里
```

### 4. style（改风格）

**目标**：调整风格，改变调性

**操作要点**：
- 调整风格描述，改变视觉调性
- 保留主体内容（人物、动作、场景）
- 改变表现方式（写实→动漫，明亮→昏暗等）
- 更新风格关键词

**示例**：
```
原提示词：写实摄影风格，明亮的光线，她站在花园里
改风格后：日本动漫风格，柔和的光线，她站在花园里，背景有樱花飘落
```

### 5. custom（自定义）

**目标**：根据用户具体意见修改

**操作要点**：
- 仔细阅读用户反馈，理解修改意图
- 保留原提示词中不需要修改的部分
- 只修改用户明确要求修改的内容
- 如果用户意见不明确，可以适当优化整体表达
- **重要**：直接给出修改后的描述，不要提及"不再"、"改为"、"从...变成..."等变化过程，也不要对比修改前后的差异

**示例**：
```
原提示词：她穿着白色连衣裙，站在窗边
用户反馈：裙子应该是蓝色的，而且要加上她在看书
修改后：她穿着蓝色连衣裙，站在窗边看书
```

**错误示例**（不要这样输出）：
```
她不再穿白色连衣裙，改为穿蓝色连衣裙，站在窗边看书
```

## 输出要求

1. **基于原提示词**：必须基于原提示词进行修改，不要完全重写
2. **保留核心要素**：保留原提示词中的核心约束和关键要素
3. **针对性调整**：根据修改类型有针对性地调整
4. **简洁输出**：只输出修改后的提示词，不要其他内容
5. **格式一致**：保持与原提示词相同的语言（中文/英文）和格式
6. **直接描述**：直接描述最终状态，不要提及变化过程
   - ❌ 错误："胸口不再挂玉牌，改为悬挂一枚铜铃铛"
   - ✅ 正确："胸口悬挂一枚小巧古朴的铜铃铛"

## 输出格式

请将修改后的提示词放在 <提示词> 标签内。
