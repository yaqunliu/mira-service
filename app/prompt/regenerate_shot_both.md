# 分镜首尾帧提示词重新生成 (V4)

## 任务说明

根据分镜剧本、角色信息和场景环境，同时生成分镜**首帧**和**尾帧**两张静态图片的提示词。这是一个**重新生成**任务，不需要参考原提示词，直接使用模板生成全新的提示词。

**V4版本的核心理念**：
1. **双帧叙事**：首帧建立分镜起点，尾帧收束分镜终点，两帧共同构成完整的视觉叙事
2. **景别自由**：根据故事需要和画面合理性，灵活选择最适合的景别
3. **时间推进**：基于分镜剧本，精准把握动作和情绪的起始与结束状态
4. **情绪刻画**：通过表情、肢体语言、眼神等细节，深度传达角色的内心世界
5. **风格融合**：根据指定的视觉风格，生成符合该风格的图片提示词

## 核心原则

### 1. 分镜融合（关键）

**核心原则**：做好当前分镜与上一个分镜的融合，避免视觉和听觉上的割裂。

**判断依据**：根据 `PREVIOUS_SHOT_INFO` 判断当前分镜与上一个分镜的关系：

| 关系类型 | 特征 | 融合策略 |
|---------|------|---------|
| **同一场景连续** | 同一地点、同一时间段、同一角色群 | 运镜延续、声场连续、避免硬切 |
| **同一场景跳跃** | 同一地点但时间/角色有跳跃 | 镜头衔接点合理、可适当使用转场 |
| **转场** | 场景/时间/角色变化 | 可使用较明显转场、声音先行 |

**融合规则**：

| 维度 | 同一场景 | 转场 |
|-----|---------|------|
| **画面风格** | 色彩、光影保持一致 | 可渐变或使用转场效果 |
| **角色状态** | 动作、表情有连贯性 | 动作可独立 |
| **环境细节** | 同一物品/元素延续 | 可更换环境 |

**融合示例**：
- 同一场景连续：上一个分镜"她坐在咖啡桌前犹豫"，当前分镜"她伸手拿咖啡杯" → 位置、姿态延续
- 转场：上一个分镜"咖啡厅内景"，当前分镜"咖啡厅外景" → 可通过窗户/门口过渡

### 2. 角色情绪分析 (V4 核心优化)

在生成提示词前，必须先分析当前分镜中角色的情绪状态。

#### 情绪分析框架

| 情绪类别 | 细分情绪 | 面部表情特征 | 肢体语言特征 | 眼神特征 |
|---------|---------|-------------|-------------|---------|
| **喜悦** | 开心、兴奋、满足 | 嘴角上扬、眼睛弯成月牙 | 身体放松、手势开放 | 明亮有神、眼角带笑 |
| **悲伤** | 失落、绝望、思念 | 眉头微蹙、嘴角下垂 | 肩膀下沉、身体蜷缩 | 目光低垂、眼神空洞 |
| **愤怒** | 生气、不满、愤恨 | 眉头紧锁、牙关紧咬 | 身体前倾、拳头紧握 | 目光锐利、眼神凌厉 |
| **恐惧** | 害怕、紧张、不安 | 眼睛睁大、嘴唇微张 | 身体僵硬、双手颤抖 | 瞳孔放大、目光闪躲 |
| **惊讶** | 震惊、意外、困惑 | 眉毛挑起、嘴巴微张 | 身体后仰、手部上扬 | 眼睛圆睁、目光聚焦 |
| **平静** | 淡然、释然、沉思 | 表情舒展、五官放松 | 姿态稳定、动作从容 | 目光平和、眼神深邃 |

### 3. 首尾帧时间推进

- **首帧**：分镜**开始**时的画面状态（动作的起点 + 起始情绪）
- **尾帧**：分镜**结束**时的画面状态（动作的终点 + 终点情绪）

### 3. 景别选择策略 (V4 导演思维)

#### 首帧景别选择指南

| 分镜类型 | 推荐景别 | 选择理由 |
|---------|---------|---------|
| 场景开篇/环境交代 | 全景/中景 | 建立空间感 |
| 单人情感戏 | 中近景/近景 | 聚焦角色情绪 |
| 双人对话/互动 | 中景/过肩镜头 | 展示人物关系 |
| 动作/肢体戏 | 中景/全景 | 展示完整动作 |
| 紧张/悬疑 | 近景/特写 | 制造压迫感 |

#### 尾帧聚焦策略

| 分镜内容类型 | 尾帧聚焦建议 |
|-------------|-------------|
| 对话/情感交流 | 眼睛特写 |
| 行走/奔跑 | 脚步特写 |
| 拿取/操作物品 | 手部与物品特写 |
| 注视/发现 | 被注视对象 |
| 紧张/恐惧 | 生理反应特写 |

### 4. 服装控制规则 (重要)

服装确定优先级：
1. **剧本明确指定** → 使用剧本描述
2. **当前章节有统一服装设定** → 使用章节设定
3. **以上都没有** → 使用角色档案中的默认服装

### 6. 风格一致性

- **必须**使用 <visual_style> 中指定的视觉风格
- 首帧和尾帧的风格描述必须保持一致
- 色彩、光影、构图都要符合指定风格的特点
