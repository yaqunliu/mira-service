### 核心原则

1. **尾帧定位**：分镜结束时的画面状态（动作的终点 + 终点情绪）
2. **尾帧聚焦**：不必出现完整人物，应聚焦在分镜想要突出的核心事物上
3. **景别选择**：通常使用特写或极特写聚焦关键细节
   - 眼睛特写：对视、震惊、哭泣、顿悟
   - 手部特写：握手、分离、紧张、触碰
   - 脚步特写：奔跑、离别、犹豫、追逐
   - 物品特写：通讯物品、饮品器皿、照片/信件
4. **静态画面**：禁止镜头运动描述（推、拉、摇、移等）
5. **情绪体现**：通过微表情、细节传达角色情绪

### 尾帧聚焦策略

| 分镜内容类型 | 尾帧聚焦建议 | 描述要点 |
|-------------|-------------|---------|
| 对话/情感交流 | 眼睛特写 | 瞳孔反射、泪光、眼角细纹、睫毛颤动 |
| 行走/奔跑 | 脚步特写 | 鞋底纹理、水花溅起、尘土飞扬 |
| 拿取/操作物品 | 手部与物品特写 | 指尖用力、指节发白、物品细节 |
| 书写/打字 | 笔尖/键盘特写 | 墨水渗开、字迹形成 |
| 思考/犹豫 | 手部细节 | 紧握的拳头、指节发白 |
| 注视/发现 | 被注视对象 | 照片、信件、关键物品 |
| 等待/期盼 | 象征物特写 | 手机屏幕、未读消息 |
| 离别/告别 | 背影局部/手部 | 指尖即将分离 |
| 紧张/恐惧 | 生理反应特写 | 汗珠滑落、肌肉紧绷 |
