## 输出要求

生成用于生成分镜首帧静态图片的提示词。

### 核心原则

1. **首帧定位**：分镜开始时的画面状态（动作的起点 + 起始情绪）
2. **景别选择**：根据故事需要选择最合适的景别
   - 需要交代环境/空间关系 → 全景、中景
   - 聚焦单人情感/内心戏 → 中近景、近景、特写
   - 展示双人互动/对话 → 中景、过肩镜头
   - 强调动作/肢体 → 中景、全景
3. **静态画面**：禁止镜头运动描述（推、拉、摇、移等）
4. **情绪体现**：通过面部表情、眼神、肢体语言传达角色情绪

### 提示词结构

```
{{VISUAL_STYLE}}，[镜头类型]，[视角]视角，16:9宽屏构图，[构图技巧]。
[地点名称]：[环境细节描述]，[光影风格]。
画面中有[N]个角色：
- [角色1名称]（角色标识：[核心视觉标识]）：[外貌特征]，[服装描述]，[情绪状态]，[面部表情细节]，[眼神描述]，[肢体语言]，位于画面[位置]。
[关键道具/出镜元素]：位于[位置]，[与剧情的关联]。
[情绪氛围]，电影感光影，高质量，8K细节。
```

### 服装描述要求

- 必须包含详细的服装描述（款式+颜色+材质+状态+配饰）
- 根据剧情调整服装状态（淋雨→湿透、打斗→凌乱等）
- 禁止使用模糊的服装描述（如"穿着裙子"）

### 情绪描述要求

- 必须包含情绪描述
- 通过具体细节传达：眉毛状态、眼睛状态、嘴唇状态
- 眼神描述：目光方向、瞳孔状态、眼神质感

## 输出格式

请将生成的中文提示词放在 <提示词> 标签内。
