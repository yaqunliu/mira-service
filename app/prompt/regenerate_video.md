# 视频提示词重新生成

## 任务说明

根据分镜剧本、首帧提示词、尾帧提示词、角色信息和台词，重新生成视频提示词。这是一个**重新生成**任务，不需要参考原提示词，直接使用模板生成全新的提示词。

视频提示词采用**三维度时间轴驱动**格式：画面 + 背景音 + 人物对白。

## 输出要求

生成具有**专业电影感**的视频提示词，采用**三维度时间轴驱动**格式。

### 核心规则

1. **输出格式**：必须严格按照以下格式输出：

```json
{
  "video_prompt": "全局氛围描述。\n\n[0-Xs] 镜头1\n画面：[0-Xs] 景别+运镜。动作描述。\n背景音：环境音；音效；音乐\n人物对白：（无）\n\n[X-Ys] 镜头2\n画面：[X-Ys] 景别+运镜。cut。动作描述。\n背景音：环境音；音效；音乐\n人物对白：[Xs-Ys] 角色：\"台词\"\n\n[Y-Zs] 镜头N（尾帧衔接）\n画面：[Y-Zs] 景别定格。动作描述，定格。\n背景音：环境音；音效；音乐\n人物对白：（无）",
  "cut_method": "方法名",
  "cut_reason": "简述镜头切换逻辑"
}
```

2. **三维度结构**：

| 维度 | 格式 | 示例 |
|-----|------|------|
| **画面** | `[时间] 景别+运镜。动作。` | `[0-1.5s] 中近景固定。她抬手拨头发。` |
| **背景音** | `环境音；音效；音乐` | `空调嗡鸣；手指摩擦声；钢琴单音` |
| **人物对白** | `[时间] 角色："台词"` 或 `（无）` | `[2.5s-4s] 她轻声道："我知道了。"` |

3. **镜头切换规则**：

| 时长 | 推荐镜头数 | 切换节奏 |
|-----|----------|---------|
| 2-3秒 | 2个 | 快节奏 |
| 4-5秒 | 2-3个 | 中等节奏 |
| 6-8秒 | 3-4个 | 正常节奏 |

4. **尾帧衔接（关键）**：

最后一个镜头的**画面描述必须与尾帧提示词完全一致**：

| 尾帧类型 | 衔接方式 |
|---------|---------|
| 眼睛特写 | 缓推聚焦，定格瞳孔细节 |
| 手部特写 | 下摇+推近，定格手指状态 |
| 物品特写 | 视线跟随，定格物品细节 |
| 表情特写 | 缓推面部，定格表情 |

5. **禁止内容**：
- ❌ 禁止：比喻、拟人、文学化描写
- ❌ 禁止：解释画面含义或情绪
- ❌ 禁止：添加输入信息中没有的元素
- ❌ 禁止：使用"情感"、"氛围"等主观词汇描述画面
- ❌ 禁止：超过 2.5 秒的单镜头

### 生成步骤

**步骤1：首尾帧分析**

分析首帧和尾帧的差异：

| 分析维度 | 首帧 | 尾帧 | 需要设计的过渡 |
|---------|------|------|--------------|
| 景别 | 从首帧提取 | 从尾帧提取 | 推/拉/切 |
| 聚焦 | 整体/局部 | 局部/特写 | 视线引导 |
| 动作 | 起始状态 | 终点状态 | 动作轨迹 |

**步骤2：镜头规划**

根据时长分配镜头：

**2-3秒（快节奏）**
```
镜头1：[0-1.5s] 首帧动作
镜头2：[1.5-3s] 尾帧衔接
```

**4-5秒（中等节奏）**
```
镜头1：[0-1.5s] 首帧动作
镜头2：[1.5-3s] 过渡动作
镜头3：[3-5s] 尾帧衔接
```

**6-8秒（正常节奏）**
```
镜头1：[0-1.5s] 首帧动作
镜头2：[1.5-3s] 过渡动作1
镜头3：[3-5s] 过渡动作2
镜头4：[5-8s] 尾帧衔接
```

**步骤3：生成三维度提示词**

**画面维度规则**：
- 只描述**动作**和**状态**（不描述情绪）
- 格式：`[时间] 景别+运镜。动作描述。`
- 景别：全景→中景→近景→特写（推进时）
- 运镜：固定/缓推/急推/横摇/跟随

**背景音维度规则**：
- 格式：`环境音；音效；音乐`
- 环境音：贯穿全片，音量可微调
- 音效：关键时间点标注（如：2.5s脚步声）
- 音乐：持续变化，标注关键节点

**人物对白维度规则**：
- 格式：`[Xs-Ys] 角色+语气："台词"`
- 无台词时：`（无）`
- 语气词：`（抽气）/（叹息）/（哽咽）`
