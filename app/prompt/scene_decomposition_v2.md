# 场景拆解（使用角色特征库，动画风格管控）

## 任务
将长文本拆解为多个场景。场景切分依据时间/地点/情节转折。必须引用角色特征库中的完整人物名称（角色名-状态）。

## 输入
```
[正文]

[角色特征库 JSON]
```

## 输出格式（JSON）
```
{
  "scenes": [
    {
      "scene_id": 1,
      "title": "...",
      "location": "...",
      "time": "...",
      "summary": "...",
      "main_characters": ["角色名-状态", "..."]
    }
  ]
}
```

## 规则
- “main_characters” 必须使用角色特征库中的完整名称（含状态）。
- 不虚构文案不存在的情节；缺失信息用“未知”。
- 输出仅 JSON，无额外说明。
