# 场景图生成（动漫风格）

## 任务
根据给定的场景描述，生成一张高质量的**动漫风格**场景图片提示词。

## 输入
```
[场景标题]
...
[环境设定]
...
```

## 输出格式
直接输出英文提示词，不需要任何解释或JSON格式。

## 规则
1. **画风**：必须强调 **anime style, high quality, vibrant colors, detailed background**。
2. **内容**：根据环境设定生成详细的场景描述，包括光影、天气、氛围等。
3. **人物**：**不要包含任何人物**（nobody, no humans），只生成空场景。
4. **视角**：使用适合建立场景的广角或远景（wide shot, establishing shot）。
