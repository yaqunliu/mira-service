## 任务要求

### 总体时长规范

**关键要求**：整个剧本文案的分镜总时长应控制在 **90-150 秒**之间

- **分镜数量**：通常拆分为 **15-25 个分镜**
- **平均时长**：每个分镜平均 5-7 秒
- **单个分镜时长上限**：**严禁超过 8 秒**。如果内容较多，请拆分为多个分镜。
- **时长计算**：确保所有分镜时长之和在 90-150 秒范围内

### 分镜拆解规则

1. **分镜编号**：使用"场景编号-分镜序号"格式（如："1-1", "1-2", "2-1"）

2. **关联场景**：每个分镜必须关联到对应的场景编号和场景标题

3. **构图要求**：
   - **每个分镜的开始必须以近景（Medium Close-up）且人物居中的构图开始。**
   - 画面应聚焦于角色的面部表情或核心动作，增强视觉冲击力。

4. **出镜角色**：列出分镜中**实际出镜**的角色
   - **必须使用角色特征库中的完整名称**（包含状态，如"陶未-青年"）
   - **核心标准：当前分镜中出现的人物必须在分镜一开始就出现在画面中，严禁在镜头中途才进入画面。**
   - **如果需要中途出现新的人物，必须拆分为一个新的分镜。**
   - 只包含实际出现在画面中的角色。

5. **声音角色**：列出分镜中**未出镜但有声音**的角色
   - 通过电话、画外音、回忆声音等方式出现的角色。
   - 必须使用角色特征库中的完整名称。

6. **台词 (narration)**：列出分镜中角色的第一人称声音（对话、心理独白、电话声音）
   - **必须以对象数组形式输出**，例如：`[{"角色": "角色A", "内容": "你好"}, {"角色": "角色B", "内容": "好久不见"}]`
   - **禁止添加第三人称旁白描述**。
   - **台词时长估算**：包含标点符号，平均每秒 3.5 个汉字。

7. **分镜时长**：控制在 3-8 秒之间
   - **严禁超过 8 秒**。
   - 如果台词内容在 8 秒内无法说完，**必须**将该分镜拆分为两个或多个分镜，并合理分配台词。
   - **计算公式**：台词字数 ÷ 3.5 + 1.5秒（留出画面停留时间），且结果不能超过 8。

8. **简要剧情**：精简描述分镜的剧情内容（30-50字）
   - 概括这个分镜发生了什么，重点描述角色的动作和情节发展。

## 重要规则

1. **单个分镜时长（硬性要求）**：
   - **严禁超过 8 秒**。
   - 每个分镜的节奏要快，保持动态感。

2. **人物出场时机（硬性要求）**：
   - **所有关联的出镜角色必须在分镜开始的第 0 秒就位于画面中。**
   - 不允许出现“人物从画外走入”或“镜头旋转到一半才看到某人”的情况。

3. **构图起始（硬性要求）**：
   - **每个分镜必须以人物近景且居中作为起始画面。**

4. **总时长控制**：
   - 所有分镜时长之和必须在 90-150 秒范围内。

5. **台词格式**：
   - 必须是对象数组格式，只包含第一人称声音。

## 正确与错误示例说明

### ✅ 正确示例

**示例1：严格控制时长与起始构图**
```json
{
  "分镜编号": "2-1",
  "出镜角色": ["陶未-青年"],
  "分镜时长": 6,
  "简要剧情": "近景居中：陶未面色苍白，眼神中透着绝望，死死盯着面前的失败报告。",
  "台词": [{"角色": "陶未-青年", "内容": "又是这样……难道我真的不行吗？"}]
}
```
*解析：时长 6s（未超8s），简要剧情指明了“近景居中”，台词为第一人称独白。*

**示例2：新人物出现强制拆分分镜**
```json
[
  {
    "分镜编号": "3-1",
    "出镜角色": ["林小雨-青年"],
    "简要剧情": "近景居中：林小雨在雨中奔跑，神色慌张。",
    "分镜时长": 5
  },
  {
    "分镜编号": "3-2",
    "出镜角色": ["林小雨-青年", "神秘人-中年"],
    "简要剧情": "近景居中：神秘人突然出现在林小雨面前挡住去路，两人对峙。",
    "分镜时长": 4
  }
]
```
*解析：神秘人出现时立即拆分为新分镜，确保每个分镜开始时角色就在画面中。*

### ❌ 错误示例

**错误1：时长超过 8 秒**
```json
❌ "分镜时长": 12,
❌ "简要剧情": "林小雨在图书馆里找了很久，终于找到了地图，然后她坐下来仔细研究，最后拿出了手机拍照。"
```
*修正：动作过多导致时长过长，应拆分为 2-3 个分镜。*

**错误2：人物中途入场**
```json
❌ "出镜角色": ["陶未-青年", "李总-中年"],
❌ "简要剧情": "近景居中：陶未正在工作，李总推门走进来，走到陶未身边。"
```
*修正：李总是在分镜中途进入的。应改为：分镜A（只有陶未），分镜B（两人都在画面中）。*

**错误3：非近景居中起始**
```json
❌ "简要剧情": "全景：整座城市被大雨笼罩，远处的图书馆灯火通明。"
```
*修正：起始画面必须是人物近景且居中。环境描述应融入角色互动的背景中。*

**错误4：包含第三人称旁白**
```json
❌ "台词": [{"角色": "旁白", "内容": "他心里感到一阵从未有过的恐惧"}]
```
*修正：应改为角色的第一人称心理独白或通过面部表情动作（简要剧情）来体现。*
