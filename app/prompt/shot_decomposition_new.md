## 任务要求

### 总体时长规范

**关键要求**：整个剧本文案的分镜总时长应控制在 **90-150 秒**之间

- **分镜数量**：通常拆分为 **10-20 个分镜**
- **平均时长**：每个分镜平均 6-8 秒
- **时长计算**：确保所有分镜时长之和在 90-150 秒范围内

### 分镜拆解规则

1. **分镜编号**：使用"场景编号-分镜序号"格式（如："1-1", "1-2", "2-1"）

2. **关联场景**：每个分镜必须关联到对应的场景编号和场景标题

3. **出镜角色**：列出分镜中**实际出镜**的角色
   - **必须使用角色特征库中的完整名称**（包含状态，如"陶未-青年"）
   - **分镜解析核心标准：分镜开始的第一幕瞬间没有出现的人，当前分镜就不出现。如果需要中途出现新的人物，必须拆分为一个新的分镜。**
   - **只包含实际出现在画面中的角色**
   - 出镜角色必须在角色特征库的"出镜角色"中存在

4. **声音角色**：列出分镜中**未出镜但有声音**的角色
   - **通过电话、画外音、回忆声音等方式出现的角色**
   - **必须使用角色特征库中的完整名称**（包含状态）
   - 声音角色必须在角色特征库的"声音角色"或"出镜角色"中存在
   - 如果分镜中没有声音角色，此字段为空数组 `[]`

5. **台词 (narration)**：列出分镜中角色的第一人称声音（对话、心理独白、电话声音）
   - **必须以对象数组形式输出**，例如：`[{"角色": "角色A", "内容": "你好"}, {"角色": "角色B", "内容": "好久不见"}]`
   - **包含以下类型的第一人称声音**：
     - 角色直接对话（面对面说的话）
     - 电话中的声音（通过电话传来的对话，角色应在"声音角色"字段中）
     - 心理独白（角色内心的想法，第一人称"我想..."）
     - 画外音（角色的声音但不在画面中，角色应在"声音角色"字段中）
   - **禁止添加第三人称旁白描述**（如"他想..."、"她的声音被雨声吞掉"等客观描述）
   - **这是动态漫画分镜，不是解说视频**，只记录角色的第一人称声音
   - 如果分镜中没有任何声音，此字段为空数组 `[]`
   - **台词字数估算**：包含标点符号，平均每秒 3.5 个汉字

6. **分镜时长**：控制在 4-12 秒之间
   - **无台词的分镜**：4-10 秒
   - **有台词的分镜**：根据台词长度确定时长 如果台词不是太长，12秒分镜可以说完 就尽量不要拆开。
   - **台词时长估算**：平均每秒 3-4 个汉字
   - **计算公式**：台词字数 ÷ 3.5 + 2秒（留出画面停留时间）
   - **示例**：
     - 20字台词：20 ÷ 3.5 + 2 ≈ 8秒
     - 35字台词：35 ÷ 3.5 + 2 ≈ 12秒

7. **简要剧情**：精简描述分镜的剧情内容（30-50字）
   - 概括这个分镜发生了什么
   - 重点描述角色的动作和情节发展
   - 示例："林小雨在图书馆发现古籍中的神秘地图，激动地用手机拍照记录"

## 重要规则

1. **总时长控制**（最重要！）：
   - **所有分镜时长之和必须在 90-150 秒范围内**
   - 分镜数量通常为 10-20 个
   - 平均每个分镜 6-8 秒
   - 拆解前先估算总时长，确保符合要求

2. **台词格式要求**：
   - **"台词"字段必须是对象数组格式**，即使只有一句对白
   - 每个对象包含 "角色" 和 "内容" 两个字段
   - **包含角色的第一人称声音**：直接对话、电话声音、心理独白、画外音
   - **禁止添加第三人称旁白描述**（如"他想..."、"声音被吞掉"等客观描述）
   - 这是动态漫画分镜，角色的第一人称声音是重点，不是第三人称解说

3. **角色名称一致性**：
   - 分镜中的"出镜角色"和"声音角色"字段**必须使用角色特征库中提供的完整名称**
   - 包含状态信息（如"陶未-青年"、"李总-中年"）
   - 不能省略状态，不能只写"陶未"
   - **"出镜角色"字段只包含实际出现在画面中的角色**
   - **"声音角色"字段只包含未出镜但有声音的角色**（电话、画外音、回忆等）

4. **单个分镜时长**：
   - 控制在 4-12 秒范围内
   - 考虑画面动作和节奏的需要
   - 根据台词长度合理分配时间

5. **分镜节奏**：
   - 每个场景控制在 2-6 个分镜
   - 避免分镜过于琐碎或冗长
   - 注意分镜之间的连贯性

6. **内容还原**：
   - 分镜内容应该忠实还原原文情节
   - 不要遗漏重要情节和角色动作

7. **首幕人物一致性规则**（极度重要）：
   - **分镜开始的第一幕瞬间没有出现的人物，在当前分镜的后续内容中绝不允许出现。**
   - 如果剧情需要引入新的人物，必须强制将其拆分为一个新的独立分镜。
   - 确保每个分镜的画面内容描述中，人物的出场时机与分镜开始时刻保持一致。

## 台词示例说明

### ✅ 正确示例（第一人称声音）

**示例1 - 直接对话**：
```json
"台词": [
  {"角色": "陶未-青年", "内容": "第十次了……又失败了"},
  {"角色": "李总-中年", "内容": "这个方案根本不行"}
]
```

**示例2 - 电话声音**（教授不在画面中，在"声音角色"）：
```json
"出镜角色": ["林小雨-青年"],
"声音角色": ["教授-中年"],
"台词": [
  {"角色": "林小雨-青年", "内容": "教授，我找到地图了！"},
  {"角色": "教授-中年", "内容": "太好了，快发给我看"}
]
```

**示例3 - 心理独白**（角色内心的想法，第一人称）：
```json
"台词": [
  {"角色": "陶未-青年", "内容": "我该怎么办？难道就这样放弃吗？"}
]
```

**示例4 - 画外音**（角色回忆/独白，不在画面中）：
```json
"出镜角色": ["林小雨-青年"],
"声音角色": ["陶未-青年"],
"台词": [
  {"角色": "陶未-青年", "内容": "那天，我第一次见到她"}
]
```

### ❌ 错误示例（第三人称旁白描述）

**错误1 - 第三人称描述**：
```json
❌ "台词": [{"角色": "旁白", "内容": "他的声音被雨声吞掉大半"}]
❌ "台词": [{"角色": "旁白", "内容": "思绪被拉回下午的会议室"}]
❌ "台词": [{"角色": "旁白", "内容": "陶未陷入了沉思"}]
```
这些都是客观描述，不是角色的第一人称声音，应该删除。

**错误2 - "他想"/"她想"的第三人称转述**：
```json
❌ "台词": [{"角色": "旁白", "内容": "他想，也许这就是命运吧"}]
```
应改为：
```json
✅ "台词": [{"角色": "陶未-青年", "内容": "也许这就是命运吧"}]
```

6. **第六步**：检查所有"台词"字段，确保只包含第一人称声音，删除所有第三人称旁白描述
