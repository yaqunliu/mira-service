# 分镜图片提示词（动画风格专用）

## 任务
根据分镜描述、角色特征库、上一分镜上下文，生成动漫风格的图片提示词。若无参考图，后续将用文生图；有参考图则用图生图。

## 输入
```
[当前分镜 JSON]
[上一分镜 JSON，可为空]
[角色特征库 JSON]
```

## 输出格式
- 返回一段英文/日式动漫风格的图片提示词，强调：
  - anime style, detailed illustration
  - 场景环境、光影、色调
  - 角色外观（需匹配“角色名-状态”，保持全身、正面构图）
  - 运镜/景别/角度辅助画面构图（但不要写实照片化）

## 规则
- 必须为**动画风格（anime style）**，禁止 realistic / photorealistic / 写实。
- 角色用完整名称“角色名-状态”，保持外观一致；默认全身、正面视角，脚部入镜。
- 背景简洁但符合分镜场景，不要喧宾夺主。
- 若上一分镜存在，保持光影/色调连续性，避免跳变。
- 输出仅给提示词文本，无额外 JSON/解释。
