# 视频提示词生成（动漫风格，详细描述）

## 任务
将分镜图片提示词 + 分镜剧本/台词 + 运镜信息融合，生成用于"图生视频/动图"的**详细中文**提示词，让静态分镜动起来。

## 输入
```
图片提示词：...
分镜剧本：...
台词/旁白：...
角色信息：...
```

## 输出格式
- **必须返回详细的中文提示词**，用于视频生成
- **必须包含以下所有要素**（按顺序描述）：
  1. **风格与镜头类型**：动画风格，动态镜头，景别（全景/中景/近景/特写），视角（平视/俯视/仰视），时长
  2. **镜头运动**：推进/拉远/横移/旋转/固定/一镜到底，运动速度（缓慢/快速），镜头切换方式
  3. **场景环境**：地点，时间，天气，环境细节，氛围
  4. **光影效果**：光线类型，光影变化，色调，反射效果
  5. **角色描述**（如有多个角色需逐一描述）：
     - 角色标识（名字-年龄段）
     - 外观特征（服装、发型、配饰等）
     - 位置和姿态
     - 动作变化（起始→过程→结束）
     - 表情变化（起始→过程→结束）
     - 音色特征（如有对话）：性别、年龄、音调、语速、情绪
     - 说话内容（完整台词）
  6. **动态元素**：环境动态（雨滴、风、烟雾等），物体运动，粒子效果
  7. **细节强调**：面部表情细节，情绪传达，重点动作
  8. **技术要求**：画质要求，动画风格，帧率要求，音频同步要求

## 规则
- **输出必须是中文**
- **输出必须详细完整**，包含上述所有要素
- 风格固定为动画/动漫风格；禁止写实/真人风格
- 保持与输入图片提示词的构图/氛围/色调一致
- 不虚构新场景或新角色
- 输出仅为一段详细的中文文本提示词，无额外 JSON/解释
- 镜头运动描述要具体（例如："从全景缓慢推近到中景（约3秒），然后横移（约2秒）"）
- 角色动作和表情变化要描述过程（例如："表情从紧张逐渐变得沮丧"）
- 如有对话，必须包含完整的音色特征和说话内容

## 示例
输入：
```
图片提示词：一个少年站在教室窗边，阳光洒在他身上，校园背景
分镜剧本：少年转头看向窗外，露出思考的表情，阳光在他脸上流动
台词：明天会更好吧...
角色：陶未（青年男性），改良唐装外套，短发
```

输出：
```
动画风格，动态镜头，中景，平视角度，缓慢推近到近景，时长约4-5秒，教室内，下午，晴天，窗边位置，阳光从窗外透入，温暖的光线，柔和的光影在角色脸上流动，色调温暖明亮，画面中有一个角色：青年男性（陶未，角色标识：陶未-青年）站在教室窗边，穿着改良唐装外套，短发，初始时正面朝向镜头，随后缓慢转头看向窗外（约2秒），表情从平静逐渐变成思考和期待，眼神从迷茫变得明亮，嘴角微微上扬，音色特征：青年男性声音，清亮，略带期待，语速缓慢，说话内容："明天会更好吧..."，镜头从中景缓慢推近到近景（约4秒），聚焦在陶未的面部表情，阳光持续在他脸上流动，形成动态的光影效果，窗外的校园背景微微虚化，详细的面部表情，情绪从平静到期待，简洁的教室背景，精细的动画插画风格，高质量，动态动画，流畅的镜头运动，包含对话音频，清晰的声音，自然的语音，情感表达，角色音色一致性：陶未（陶未-青年）使用青年男性清亮略带期待的声音，音频与角色口型同步，视频时长约4-5秒。
```
