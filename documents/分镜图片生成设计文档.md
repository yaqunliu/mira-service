# 分镜图片生成设计文档

## 一、功能概述

本文档描述分镜（Shot）图片生成功能的设计与实现，包括：

1. **批量生成**：一键生成创作下所有分镜的图片
2. **单个重新生成**：重新生成指定分镜的图片（支持更新提示词）

## 三、数据模型

### 3.1 Shot 模型

```python
class Shot(Base):
    __tablename__ = "shots"
    
    shot_id = Column(Integer, primary_key=True)
    title = Column(String(200), nullable=False)
    shot_number = Column(Integer, nullable=False)
    description = Column(Text)           # 分镜描述
    narration = Column(Text)             # 旁白/解说词
    image_prompt = Column(Text)          # 图片生成提示词（AI 生成）
    image_url = Column(String(500))      # 生成的图片 URL
    scene_id = Column(Integer, ForeignKey("scenes.scene_id"))
```

### 3.2 Creation 状态流转

```
CREATED → PLAYBOOK_GENERATED → CHARACTER_GENERATED → SCENE_GENERATED → ...
                                                          ↑
                                                    分镜图片生成完成
```

## 四、API 接口

### 4.1 批量生成分镜图片

#### 请求

```http
POST /api/v1/creations/{creation_id}/generate-shots
Content-Type: application/json
Authorization: Bearer {token}
```

#### 请求体

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| `force_regenerate` | boolean | 否 | 是否强制重新生成已有图片的分镜，默认 `false` |
| `shot_ids` | array | 否 | 指定分镜 ID 列表，为空则生成所有分镜 |

```json
{
    "force_regenerate": false,
    "shot_ids": null
}
```

#### 响应

```json
{
    "code": 200,
    "data": {
        "task_id": "abc-123-def-456",
        "creation_id": 123
    },
    "message": "分镜图片批量生成任务已启动"
}
```

#### 错误响应

| 状态码 | 说明 |
|--------|------|
| 400 | 创作项目正在执行其他任务 |
| 403 | 无权限操作该创作项目 |
| 404 | 创作项目不存在 |

### 4.3 重新生成分镜图片

该接口会：
1. 更新提示词（如果提供）
2. 清空现有的 `image_url`
3. 启动生成任务

#### 请求

```http
POST /api/v1/shots/{shot_id}/regenerate
Content-Type: application/json
Authorization: Bearer {token}
```

#### 请求体

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| `image_prompt` | string | 否 | 新的图片提示词，不传则使用现有提示词 |

```json
{
    "image_prompt": "新的图片提示词..."
}
```

#### 响应

```json
{
    "code": 200,
    "data": {
        "task_id": "xyz-789-abc",
        "shot_id": 1,
        "creation_id": 123,
        "image_prompt": "更新后的提示词"
    },
    "message": "分镜图片重新生成任务已启动"
}
```

## 五、Celery 任务实现

### 5.1 任务模块

位置：`app/tasks/shot_task.py`

### 5.2 任务类型

| 任务名 | 说明 |
|--------|------|
| `generate_single_shot_image_task` | 生成单个分镜图片（子任务） |
| `generate_creation_shots_task` | 批量生成创作下所有分镜（主任务） |
| `generate_shots_by_ids_task` | 生成指定分镜列表（线程池并发） |

### 5.3 批量生成流程

```python
@celery_app.task(bind=True, name="generate_creation_shots_task")
def generate_creation_shots_task(self, creation_id: int, force_regenerate: bool = False):
    """
    1. 查询创作下所有场景和分镜
    2. 筛选需要生成图片的分镜（无 image_url 或强制重新生成）
    3. 使用 Celery Group 并发执行所有子任务
    4. 等待所有子任务完成
    5. 汇总结果，更新 Creation 状态
    """
```

### 5.4 单个分镜生成流程

```python
def _generate_single_shot_image(shot_id: int, creation_id: int) -> dict:
    """
    1. 查询分镜信息
    2. 检查是否已有图片（跳过）
    3. 检查是否有 image_prompt（必须）
    4. 调用 AI 生图 API
    5. 下载图片并上传到 US3
    6. 更新 Shot.image_url
    7. 返回结果
    """
```

### 5.5 图片存储路径

```
creations/{creation_id}/shots/{shot_id}/image_{uuid}.png
```

## 六、前端集成

### 6.1 批量生成流程

```typescript
// 1. 启动任务
const taskId = await startGenerateShots(creationId);

// 2. 轮询进度
pollTaskProgress(taskId, {
  onProgress: (data) => {
    // 更新进度条
    setProgress(data.progress);
    // 实时更新已完成的分镜图片
    data.scenes.forEach(scene => {
      scene.shots.forEach(shot => {
        if (shot.image_url) {
          updateShotImage(shot.shot_id, shot.image_url);
        }
      });
    });
  },
  onComplete: (data) => {
    showSuccess('生成完成');
  },
  onError: (error) => {
    showError(error);
  }
});
```

### 6.2 单个重新生成流程

```typescript
// 1. 启动任务（传入新的提示词）
const taskId = await regenerateShot(shotId, newPrompt);

// 2. 轮询任务状态
pollSingleShotTask(taskId, {
  onSuccess: (imageUrl) => {
    updateShotImage(shotId, imageUrl);
    showSuccess('重新生成成功');
  },
  onError: (error) => {
    showError(error);
  }
});
```

### 6.3 轮询建议

- **轮询间隔**：2-3 秒
- **超时处理**：建议设置最大轮询时间（如 30 分钟）
- **错误重试**：遇到网络错误时可适当重试

## 八、注意事项

1. **任务冲突**：一个创作同时只能执行一个任务，通过 `current_task_id` 字段控制
2. **提示词必须**：分镜必须有 `image_prompt` 才能生成图片
3. **降级处理**：US3 上传失败时，会使用临时 URL（AI 服务返回的）
4. **状态同步**：任务完成后会自动清空 `creation.current_task_id`
5. **并发控制**：`generate_shots_by_ids_task` 使用线程池，最多 5 个并发
