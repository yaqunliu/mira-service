# 测试接口说明

## 添加测试积分接口

### 接口信息

- **路径**: `POST /api/v1/points/test/add-points`
- **权限**: 需要登录认证（Bearer Token）
- **限制**: 仅在 `DEBUG=True` 时可用

### 请求参数

```json
{
    "user_id": 1,
    "points": 1000,
    "description": "测试添加积分"  // 可选
}
```

| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| `user_id` | int | 是 | 要添加积分的用户ID |
| `points` | int | 是 | 要添加的积分数量（必须大于0） |
| `description` | string | 否 | 描述信息（可选） |

### 响应示例

```json
{
    "code": 200,
    "data": {
        "record_id": 123,
        "points_added": 1000,
        "balance": {
            "total_points": 1500,
            "available_points": 1500,
            "frozen_points": 0,
            "today_consumed": 0,
            "month_consumed": 0,
            "points_by_type": [
                {
                    "points_type": "normal",
                    "points": 1500,
                    "expires_at": null
                }
            ]
        },
        "message": "成功为用户 1 添加 1000 积分"
    },
    "message": "添加积分成功"
}
```

### 错误响应

#### DEBUG模式未启用

```json
{
    "detail": "此接口仅在DEBUG模式下可用"
}
```

状态码: 403

## curl 调用示例

### 1. 基本调用（添加1000积分）

```bash
curl -X POST "http://localhost:8000/api/v1/points/test/add-points" \
  -H "Authorization: Bearer YOUR_ACCESS_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{
    "user_id": 1,
    "points": 1000,
    "description": "测试添加积分"
  }'
```

### 2. 添加大量积分（10000积分）

```bash
curl -X POST "http://localhost:8000/api/v1/points/test/add-points" \
  -H "Authorization: Bearer YOUR_ACCESS_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{
    "user_id": 1,
    "points": 10000
  }'
```

### 3. 使用环境变量（推荐）

```bash
# 设置环境变量
export API_BASE_URL="http://localhost:8000"
export ACCESS_TOKEN="YOUR_ACCESS_TOKEN"
export USER_ID=1

# 调用接口
curl -X POST "${API_BASE_URL}/api/v1/points/test/add-points" \
  -H "Authorization: Bearer ${ACCESS_TOKEN}" \
  -H "Content-Type: application/json" \
  -d "{
    \"user_id\": ${USER_ID},
    \"points\": 1000,
    \"description\": \"测试添加积分\"
  }"
```

## 使用说明

### 1. 启用DEBUG模式

在 `.env` 文件中设置：

```env
DEBUG=True
```

或者在启动时设置环境变量：

```bash
DEBUG=True python -m uvicorn app.main:app --reload
```

### 2. 获取访问令牌

首先需要登录获取 token：

```bash
# 登录获取token
curl -X POST "http://localhost:8000/api/v1/auth/login" \
  -H "Content-Type: application/json" \
  -d '{
    "username": "your_username",
    "password": "your_password"
  }'
```

从响应中获取 `access_token`，然后用于后续请求。

### 3. 验证积分添加

添加积分后，可以通过以下接口验证：

```bash
# 查询积分余额
curl -X GET "http://localhost:8000/api/v1/points/balance" \
  -H "Authorization: Bearer YOUR_ACCESS_TOKEN"
```

---

## 注意事项

1. **仅限测试环境**: 此接口仅在 `DEBUG=True` 时可用，生产环境会自动禁用
2. **需要认证**: 必须提供有效的 Bearer Token
3. **积分数量**: `points` 必须大于0
4. **记录信息**: 所有测试添加的积分都会记录操作者信息（`added_by`、`added_by_username`）
5. **记录类型**: 测试添加的积分记录类型为 `reward`，操作类型为 `test_add_points`

---

## 完整测试流程示例

```bash
# 1. 登录获取token
TOKEN=$(curl -s -X POST "http://localhost:8000/api/v1/auth/login" \
  -H "Content-Type: application/json" \
  -d '{"username":"test_user","password":"test_password"}' \
  | jq -r '.data.access_token')

# 2. 添加1000积分到用户ID为1的账户
curl -X POST "http://localhost:8000/api/v1/points/test/add-points" \
  -H "Authorization: Bearer ${TOKEN}" \
  -H "Content-Type: application/json" \
  -d '{
    "user_id": 1,
    "points": 1000,
    "description": "测试添加积分"
  }' | jq

# 3. 验证积分余额
curl -X GET "http://localhost:8000/api/v1/points/balance" \
  -H "Authorization: Bearer ${TOKEN}" | jq
```
