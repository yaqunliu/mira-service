# 视频合成设计文档

## 一、功能概述

本文档描述完整视频生成功能的设计与实现。该功能将音频生成、字幕生成、视频片段生成和最终视频合成整合到一个任务中，前端只需调用一次接口，即可等待最终视频生成完成。

## 三、技术栈

### 3.1 FFmpeg

系统使用 **FFmpeg** 进行视频处理：

- **图片转视频**：使用 `zoompan` 滤镜生成带特效的视频片段
- **视频拼接**：使用 `concat` 协议拼接多个视频片段
- **音视频合并**：合并视频、音频和字幕
- **字幕渲染**：使用 `subtitles` 滤镜渲染字幕

### 3.2 视频特效

系统支持以下视频特效（随机选择）：

| 特效名称 | 说明 | FFmpeg 滤镜 |
|---------|------|------------|
| `pan_left_to_right` | 从左到右平移 | `zoompan=z=1.3:d={duration}:x='(iw-iw/zoom)*on/{duration}':y='ih/2-(ih/zoom/2)':s=1920x1080:fps=30` |
| `pan_right_to_left` | 从右到左平移 | `zoompan=z=1.3:d={duration}:x='(iw-iw/zoom)*(1-on/{duration})':y='ih/2-(ih/zoom/2)':s=1920x1080:fps=30` |
| `pan_top_to_bottom` | 从上到下平移 | `zoompan=z=1.3:d={duration}:x='iw/2-(iw/zoom/2)':y='(ih-ih/zoom)*on/{duration}':s=1920x1080:fps=30` |
| `pan_bottom_to_top` | 从下到上平移 | `zoompan=z=1.3:d={duration}:x='iw/2-(iw/zoom/2)':y='(ih-ih/zoom)*(1-on/{duration})':s=1920x1080:fps=30` |

所有特效都包含：
- **缩放**：1.3倍放大
- **分辨率**：1920x1080 (16:9)
- **帧率**：30fps

## 六、Celery 任务实现

### 6.1 任务模块

位置：`app/tasks/full_generation_task.py`

### 6.2 任务类型

| 任务名 | 说明 |
|--------|------|
| `generate_full_video_task` | 完整视频生成任务（主任务） |
| `_generate_single_shot_audio` | 生成单个分镜音频（线程函数） |
| `_merge_audio_files` | 合并多个音频文件 |
| `_generate_srt` | 生成 SRT 字幕文件 |
| `_generate_single_shot_video` | 生成单个分镜的视频片段 |
| `_concat_videos` | 拼接多个视频 |
| `_merge_video_audio_subtitle` | 合并视频、音频和字幕 |

### 6.3 完整生成流程

```python
@celery_app.task(bind=True, name="generate_full_video_task")
def generate_full_video_task(self, creation_id: int, voice_id: str, voice_speed: float = 1.0, force_regenerate: bool = False):
    """
    完整视频生成任务，包含4个阶段：
    
    阶段1: 生成音频
    - 如果已存在音频和字幕且不强制重新生成，则跳过
    - 否则并发生成所有分镜的音频（最多3个并发）
    
    阶段2: 合并音频和字幕
    - 如果已存在，则跳过
    - 否则合并音频并生成字幕
    
    阶段3: 生成视频片段
    - 为每个分镜图片生成带特效的视频片段
    - 视频时长 = 对应音频的时长
    - 并发生成（最多3个并发）
    
    阶段4: 合并最终视频
    - 拼接所有视频片段
    - 合并音频和字幕
    - 上传到US3
    - 更新创作状态为 VIDEO_SYNTHESIZED
    """
```

## 七、前端集成

### 7.1 完整生成流程

```typescript
// 1. 启动任务
const taskId = await startGenerateVideo(creationId, {
  voice_id: "54a5170264694bfc8e9ad98df7bd89c3",
  voice_speed: 1.0
});

// 2. 轮询进度
pollTaskProgress(taskId, {
  onProgress: (data) => {
    const progress = data.progress;
    // 显示当前阶段
    const stageNames = {
      "generating_audio": "生成音频",
      "merging_audio": "合并音频和字幕",
      "generating_video": "生成视频片段",
      "merging_video": "合并最终视频"
    };
    
    showStatus(stageNames[progress.stage] || "处理中...");
    
    // 更新进度条
    if (progress.total) {
      setProgress(progress.completed / progress.total);
    } else {
      setProgress(progress.current_stage / progress.total_stages);
    }
  },
  onComplete: (data) => {
    const resource = data.resource;
    // 更新创作视频URL
    updateCreationVideo(resource.video_url);
    showSuccess('视频生成完成');
  },
  onError: (error) => {
    showError(error);
  }
});
```

### 7.2 轮询建议

- **轮询间隔**：2-3 秒
- **超时处理**：建议设置最大轮询时间（如 60 分钟，视频生成较耗时）
- **错误重试**：遇到网络错误时可适当重试

## 八、注意事项

1. **FFmpeg 依赖**：系统需要安装 FFmpeg，Docker 镜像已包含
2. **字体文件**：字幕渲染需要字体文件，系统会自动下载并缓存
3. **并发控制**：音频和视频生成都限制为最多3个并发，避免过多FFmpeg进程
4. **临时文件清理**：所有临时文件在处理完成后都会自动清理
5. **视频特效**：每个分镜随机选择一种特效，增加视频动感
6. **排序规则**：视频片段按 (scene_id, shot_number) 排序，确保顺序正确
7. **跳过机制**：如果音频和字幕已存在且不强制重新生成，会跳过音频生成阶段
8. **状态同步**：任务完成后会自动更新 `creation.status` 为 `VIDEO_SYNTHESIZED`

## 十一、错误处理

### 11.1 常见错误

| 错误类型 | 原因 | 处理方式 |
|---------|------|---------|
| FFmpeg 执行失败 | 命令错误或资源不足 | 记录错误，任务失败 |
| 图片下载失败 | 网络问题 | 重试，最多3次 |
| 音频生成失败 | TTS 服务问题 | 跳过该分镜，继续处理其他分镜 |
| US3 上传失败 | 网络或权限问题 | 记录错误，任务失败 |

### 11.2 日志记录

所有错误都会记录详细日志，包括：
- 失败的分镜ID
- FFmpeg 命令和错误输出
- 错误堆栈信息

## 十二、性能优化

1. **并发控制**：限制并发数，避免过多FFmpeg进程导致系统资源耗尽
2. **临时文件管理**：及时清理临时文件，避免磁盘空间不足
3. **跳过已生成内容**：如果音频和字幕已存在，跳过音频生成阶段
4. **视频拼接优化**：使用 `-c copy` 参数进行视频拼接，避免重新编码

## 十三、与分步生成的区别

### 13.1 完整生成（推荐）

- **优点**：前端只需调用一次接口，等待最终视频即可
- **适用场景**：从头开始生成视频，或需要重新生成所有内容

### 13.2 分步生成

- **优点**：可以分步查看进度，更灵活
- **适用场景**：需要分步查看和调整的场景

两种方式可以配合使用，根据实际需求选择。
