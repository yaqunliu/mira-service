# 角色图片生成设计文档

## 一、功能概述

本文档描述角色（Character）图片生成功能的设计与实现，包括：

1. **批量生成**：一键生成创作下所有角色的图片
2. **单个重新生成**：重新生成指定角色的图片（支持更新视觉风格）

## 三、数据模型

### 3.1 Character 模型

```python
class Character(Base):
    __tablename__ = "characters"
    
    character_id = Column(Integer, primary_key=True)
    name = Column(String(100), nullable=False)          # 角色名称
    status = Column(String(20), default="new")          # 状态: new, generated, confirmed
    basic_info = Column(String(500))                   # 基本信息描述
    appearance = Column(Text)                           # 外貌描述
    body = Column(Text)                                 # 身材描述
    hair = Column(Text)                                 # 发型描述
    clothing = Column(Text)                             # 服装描述
    tags = Column(ARRAY(String))                        # 特征标签
    image_prompt = Column(Text)                         # 图片生成提示词（AI 生成）
    visual_style = Column(String(100))                  # 视觉风格
    image_url = Column(String(500))                     # 生成的图片 URL
    novel_id = Column(Integer, ForeignKey("novels.novel_id"))
    creation_id = Column(Integer, ForeignKey("creations.creation_id"))
```

### 3.2 Creation 状态流转

```
CREATED → PLAYBOOK_GENERATED → CHARACTER_GENERATED → SCENE_GENERATED → ...
                                    ↑
                            角色图片生成完成
```

## 四、API 接口

### 4.1 批量生成角色图片

#### 请求

```http
POST /api/v1/characters/generate-images
Content-Type: application/json
Authorization: Bearer {token}
```

#### 请求体

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| `character_ids` | array[int] | 是 | 角色ID列表 |
| `visual_style` | string | 否 | 视觉风格，默认使用系统提示词中的风格 |

```json
{
    "character_ids": [1, 2, 3],
    "visual_style": "写实风格，中国古代宫廷风格"
}
```

#### 响应

```json
{
    "code": 200,
    "data": {
        "task_id": "abc-123-def-456",
        "message": "角色图片生成任务已启动"
    },
    "message": "成功"
}
```

#### 错误响应

| 状态码 | 说明 |
|--------|------|
| 400 | 角色ID列表为空或角色不存在 |
| 500 | 任务创建失败 |

## 五、Celery 任务实现

### 5.1 任务模块

位置：`app/tasks/character_task.py`

### 5.2 任务类型

| 任务名 | 说明 |
|--------|------|
| `generate_character_image_task` | 批量生成角色图片（主任务） |
| `_generate_single_character_image` | 生成单个角色图片（线程函数） |

### 5.3 批量生成流程

```python
@celery_app.task(bind=True, name="generate_character_image_task")
def generate_character_image_task(self, character_ids: List[int], visual_style: str):
    """
    1. 验证角色ID列表
    2. 使用线程池并发执行所有子任务（最多5个并发）
    3. 收集结果并更新进度
    4. 返回汇总结果
    """
```

### 5.4 单个角色生成流程

```python
def _generate_single_character_image(character_id: int, visual_style: str) -> dict:
    """
    1. 查询角色信息
    2. 读取角色生成提示词模板（character.md）
    3. 构建完整的图片生成提示词：
       - 系统提示词（风格要求）
       - 基本信息
       - 外貌特征
       - 身材特征
       - 发型
       - 服装
       - 特征标签
    4. 调用 AI 生图 API（文生图）
    5. 下载图片并上传到 US3
    6. 更新 Character.image_url 和 image_prompt
    7. 更新 Creation 状态为 CHARACTER_GENERATED
    8. 返回结果
    """
```

### 5.5 图片存储路径

```
characters/{character_id}/image_{uuid}.png
```

### 5.6 提示词生成规则

角色图片生成使用以下提示词模板：

1. **系统提示词**（`app/prompt/character.md`）：
   - 构图要求：正面视角，全身构图
   - 风格定位：手绘古风平面画风
   - 人物细节：表情设定为"目光坚定"
   - 背景要求：纯净浅色系背景

2. **角色信息拼接**：
   ```
   {系统提示词}
   基本信息：{basic_info}，
   外貌特征：{appearance}，
   身材特征：{body}，
   发型：{hair}，
   服装：{clothing}，
   特征标签：{tags}。
   ```

## 六、前端集成

### 6.1 批量生成流程

```typescript
// 1. 启动任务
const taskId = await startGenerateCharacterImages(characterIds, visualStyle);

// 2. 轮询进度
pollTaskProgress(taskId, {
  onProgress: (data) => {
    // 更新进度条
    setProgress(data.progress);
    // 显示当前进度
    showProgress(`${data.progress.completed}/${data.progress.total}`);
  },
  onComplete: (data) => {
    // 更新角色图片
    data.resource.results.forEach(result => {
      if (result.success) {
        updateCharacterImage(result.character_id, result.image_url);
      }
    });
    showSuccess('生成完成');
  },
  onError: (error) => {
    showError(error);
  }
});
```

### 6.2 轮询建议

- **轮询间隔**：2-3 秒
- **超时处理**：建议设置最大轮询时间（如 10 分钟）
- **错误重试**：遇到网络错误时可适当重试

## 七、注意事项

1. **并发控制**：使用线程池，最多 5 个并发，避免过多请求导致 API 限流
2. **降级处理**：US3 上传失败时，会使用临时 URL（AI 服务返回的）
3. **状态同步**：任务完成后会自动更新 `creation.status` 为 `CHARACTER_GENERATED`
4. **提示词模板**：角色图片生成使用固定的提示词模板，确保风格一致性
5. **错误处理**：单个角色生成失败不影响其他角色，任务会继续执行

## 九、与分镜图片生成的关系

角色图片生成完成后，在生成分镜图片时会：

1. **图生图模式**：如果分镜关联了角色，且角色已有图片，会使用角色的图片作为参考，进行图生图
2. **文生图模式**：如果分镜没有关联角色或角色没有图片，则使用文生图模式

这样可以确保分镜中的角色形象与角色图片保持一致。
