# 部署文档

## 一、概述

本文档描述 AI 视频生成系统的部署方法，包括开发环境、生产环境和 Docker 部署。

## 二、环境要求

### 2.1 系统要求

- **操作系统**：Linux / macOS / Windows (WSL2)
- **Python**：3.10+
- **PostgreSQL**：12+
- **Redis**：6+
- **FFmpeg**：4.0+ (用于视频处理)

### 2.2 硬件要求

**开发环境**：
- CPU：2核+
- 内存：4GB+
- 磁盘：20GB+

**生产环境**：
- CPU：4核+
- 内存：8GB+
- 磁盘：100GB+ (根据视频存储需求)

## 三、开发环境部署

### 3.1 安装依赖

#### 安装 Python 和 PostgreSQL

**macOS**:
```bash
# 使用 Homebrew
brew install python@3.11 postgresql@15 redis

# 启动服务
brew services start postgresql@15
brew services start redis
```

**Ubuntu/Debian**:
```bash
sudo apt-get update
sudo apt-get install -y python3.11 python3.11-venv postgresql-15 redis-server ffmpeg

# 启动服务
sudo systemctl start postgresql
sudo systemctl start redis
```

#### 安装 uv（Python 包管理器）

```bash
pip install uv
```

### 3.2 配置数据库

```bash
# 创建数据库
createdb video_generator

# 或使用 psql
psql -U postgres
CREATE DATABASE video_generator;
```

### 3.3 配置环境变量

```bash
# 复制环境变量模板
cp env.example .env

# 编辑 .env 文件
vim .env
```

配置以下关键变量：

```env
# 数据库配置
DATABASE_HOST=localhost
DATABASE_PORT=5432
DATABASE_USER=postgres
DATABASE_PASSWORD=your_password
DATABASE_NAME=video_generator

# Redis配置
REDIS_BROKER_URL=redis://localhost:6379/0
REDIS_BACKEND_URL=redis://localhost:6379/1

# JWT配置
SECRET_KEY=your-secret-key-here

# AI服务配置
OPENAI_API_KEY=your-openai-api-key
OPENAI_BASE_URL=https://api.openai.com/v1
LLM_MODEL_NAME=your-model-name
IMAGE_MODEL_NAME=your-image-model-name

# Fish Audio配置
FISH_AUDIO_API_KEY=your-fish-audio-api-key
FISH_AUDIO_DEFAULT_VOICE_ID=54a5170264694bfc8e9ad98df7bd89c3

# 云存储配置
US3_PUBLIC_KEY=your-us3-public-key
US3_PRIVATE_KEY=your-us3-private-key
US3_BUCKET=your-bucket-name
US3_REGION=your-region
```

### 3.4 初始化数据库

```bash
# 执行数据库迁移
uv run alembic upgrade head

# 创建超级用户
uv run python scripts/create_superuser.py
```

### 3.5 启动服务

#### 启动 FastAPI 服务

```bash
# 开发模式（自动重载）
uv run uvicorn app.main:app --reload --host 0.0.0.0 --port 8000

# 或使用启动脚本
uv run python run.py
```

#### 启动 Celery Worker

**重要**：Celery Worker 必须在项目根目录下启动。

```bash
# 方式1: 使用启动脚本（推荐）
./start_celery.sh

# 方式2: 手动启动
uv run celery -A app.core.celery_app.app worker -l INFO

# 方式3: 后台运行
uv run celery -A app.core.celery_app.app worker -l INFO --detach
```

### 3.6 验证部署

访问以下地址验证服务是否正常运行：

- **应用首页**: http://localhost:8100/
- **API文档**: http://localhost:8100/docs
- **健康检查**: http://localhost:8100/health

## 四、Docker 部署

### 4.1 使用 Docker Compose（推荐）

#### 准备环境变量

```bash
# 复制环境变量模板
cp env.example .env

# 编辑 .env 文件，配置数据库连接等信息
vim .env
```

**注意**：使用 Docker Compose 时，数据库连接应使用服务名：

```env
DATABASE_HOST=postgres  # 使用服务名，不是 localhost
DATABASE_PORT=5432
DATABASE_USER=postgres
DATABASE_PASSWORD=password
DATABASE_NAME=video_generator

REDIS_BROKER_URL=redis://redis:6379/0
REDIS_BACKEND_URL=redis://redis:6379/1
```

#### 启动所有服务

```bash
# 构建并启动所有服务
docker-compose up -d

# 查看日志
docker-compose logs -f api

# 查看所有服务状态
docker-compose ps
```

#### 初始化数据库

```bash
# 进入 API 容器
docker-compose exec api bash

# 执行数据库迁移
uv run alembic upgrade head

# 创建超级用户
uv run python scripts/create_superuser.py
```

#### 启动 Celery Worker

```bash
# 进入 API 容器
docker-compose exec api bash

# 启动 Celery Worker
uv run celery -A app.core.celery_app.app worker -l INFO
```

**或使用单独的容器运行 Celery**：

在 `docker-compose.yml` 中添加：

```yaml
  celery:
    build: .
    container_name: video_generator_celery
    env_file:
      - .env
    environment:
      - LANG=C.UTF-8
      - LC_ALL=C.UTF-8
    depends_on:
      - postgres
      - redis
    volumes:
      - ./uploads:/app/uploads
      - ./logs:/app/logs
      - /tmp:/tmp
    networks:
      - video_generator_network
    command: celery -A app.core.celery_app.app worker -l INFO
```

然后启动：

```bash
docker-compose up -d celery
```

### 4.2 单独使用 Docker

#### 构建镜像

```bash
docker build -t video-generator .
```

#### 运行容器

```bash
docker run -d \
  --name video-generator-api \
  -p 8000:8000 \
  --env-file .env \
  -v $(pwd)/uploads:/app/uploads \
  -v $(pwd)/logs:/app/logs \
  video-generator
```

## 五、生产环境部署

### 5.1 使用 Docker Compose（推荐）

生产环境建议使用 Docker Compose，便于管理和扩展。

#### 优化配置

创建 `docker-compose.prod.yml`：

```yaml
version: '3.8'

services:
  postgres:
    image: postgres:15
    container_name: video_generator_db
    environment:
      POSTGRES_DB: video_generator
      POSTGRES_USER: postgres
      POSTGRES_PASSWORD: ${DATABASE_PASSWORD}
    volumes:
      - postgres_data:/var/lib/postgresql/data
    networks:
      - video_generator_network
    restart: always

  redis:
    image: redis:7-alpine
    container_name: video_generator_redis
    volumes:
      - redis_data:/data
    networks:
      - video_generator_network
    restart: always

  api:
    build: .
    container_name: video_generator_api
    env_file:
      - .env
    depends_on:
      - postgres
      - redis
    volumes:
      - ./uploads:/app/uploads
      - ./logs:/app/logs
    networks:
      - video_generator_network
    restart: always
    command: uvicorn app.main:app --host 0.0.0.0 --port 8000 --workers 4

  celery:
    build: .
    container_name: video_generator_celery
    env_file:
      - .env
    depends_on:
      - postgres
      - redis
    volumes:
      - ./uploads:/app/uploads
      - ./logs:/app/logs
    networks:
      - video_generator_network
    restart: always
    command: celery -A app.core.celery_app.app worker -l INFO --concurrency=4

volumes:
  postgres_data:
  redis_data:

networks:
  video_generator_network:
    driver: bridge
```

#### 启动服务

```bash
docker-compose -f docker-compose.prod.yml up -d
```

### 5.2 使用 Nginx 反向代理

#### Nginx 配置示例

```nginx
server {
    listen 80;
    server_name your-domain.com;

    location / {
        proxy_pass http://localhost:8000;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Proto $scheme;
    }
}
```

#### 使用 HTTPS

```nginx
server {
    listen 443 ssl;
    server_name your-domain.com;

    ssl_certificate /path/to/cert.pem;
    ssl_certificate_key /path/to/key.pem;

    location / {
        proxy_pass http://localhost:8000;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Proto $scheme;
    }
}
```

### 5.3 使用 systemd 管理服务

#### 创建 systemd 服务文件

`/etc/systemd/system/video-generator-api.service`:

```ini
[Unit]
Description=Video Generator API
After=network.target

[Service]
Type=simple
User=www-data
WorkingDirectory=/path/to/mira-service
Environment="PATH=/path/to/venv/bin"
ExecStart=/path/to/venv/bin/uvicorn app.main:app --host 0.0.0.0 --port 8000 --workers 4
Restart=always

[Install]
WantedBy=multi-user.target
```

`/etc/systemd/system/video-generator-celery.service`:

```ini
[Unit]
Description=Video Generator Celery Worker
After=network.target

[Service]
Type=simple
User=www-data
WorkingDirectory=/path/to/mira-service
Environment="PATH=/path/to/venv/bin"
ExecStart=/path/to/venv/bin/celery -A app.core.celery_app.app worker -l INFO --concurrency=4
Restart=always

[Install]
WantedBy=multi-user.target
```

#### 启动服务

```bash
sudo systemctl daemon-reload
sudo systemctl enable video-generator-api
sudo systemctl enable video-generator-celery
sudo systemctl start video-generator-api
sudo systemctl start video-generator-celery
```

## 六、监控和日志

### 6.1 日志管理

日志文件位置：`logs/app.log`

#### 日志级别

- **DEBUG**：详细调试信息
- **INFO**：一般信息
- **WARNING**：警告信息
- **ERROR**：错误信息

#### 日志轮转

建议使用 `logrotate` 进行日志轮转：

```bash
# /etc/logrotate.d/video-generator
/path/to/mira-service/logs/*.log {
    daily
    rotate 7
    compress
    delaycompress
    notifempty
    create 0640 www-data www-data
    sharedscripts
}
```

### 6.2 监控建议

- **应用监控**：使用 Prometheus + Grafana
- **日志监控**：使用 ELK Stack 或 Loki
- **任务监控**：使用 Flower 监控 Celery 任务

#### 安装 Flower（Celery 监控）

```bash
uv run pip install flower

# 启动 Flower
uv run celery -A app.core.celery_app.app flower
```

访问：http://localhost:5555

## 七、备份和恢复

### 7.1 数据库备份

```bash
# 备份
pg_dump -U postgres video_generator > backup_$(date +%Y%m%d).sql

# 恢复
psql -U postgres video_generator < backup_20240101.sql
```

### 7.2 文件备份

```bash
# 备份上传文件
tar -czf uploads_backup_$(date +%Y%m%d).tar.gz uploads/

# 备份日志
tar -czf logs_backup_$(date +%Y%m%d).tar.gz logs/
```

### 7.3 自动备份脚本

```bash
#!/bin/bash
# backup.sh

BACKUP_DIR="/path/to/backups"
DATE=$(date +%Y%m%d_%H%M%S)

# 备份数据库
pg_dump -U postgres video_generator > $BACKUP_DIR/db_$DATE.sql

# 备份文件
tar -czf $BACKUP_DIR/uploads_$DATE.tar.gz uploads/

# 删除7天前的备份
find $BACKUP_DIR -name "*.sql" -mtime +7 -delete
find $BACKUP_DIR -name "*.tar.gz" -mtime +7 -delete
```

添加到 crontab：

```bash
# 每天凌晨2点执行备份
0 2 * * * /path/to/backup.sh
```

## 八、性能优化

### 8.1 数据库优化

- **连接池**：配置合适的数据库连接池大小
- **索引优化**：根据查询场景添加合适的索引
- **查询优化**：使用 `selectinload` 或 `joinedload` 优化关联查询

### 8.2 应用优化

- **Worker 数量**：根据 CPU 核心数调整 Worker 数量
- **并发控制**：限制 Celery 任务的并发数
- **缓存**：使用 Redis 缓存频繁查询的数据

### 8.3 存储优化

- **云存储**：使用 CDN 加速媒体文件访问
- **文件清理**：定期清理临时文件和过期文件

## 九、安全建议

### 9.1 环境变量安全

- **不要提交 `.env` 文件到版本控制**
- **使用强密码和密钥**
- **定期轮换密钥**

### 9.2 网络安全

- **使用 HTTPS**：生产环境必须使用 HTTPS
- **防火墙配置**：只开放必要的端口
- **CORS 配置**：限制允许的前端域名

### 9.3 数据库安全

- **使用强密码**
- **限制数据库访问**：只允许应用服务器访问
- **定期备份**：确保数据安全

## 十、故障排查

### 10.1 常见问题

#### 数据库连接失败

```bash
# 检查数据库服务是否运行
sudo systemctl status postgresql

# 检查连接配置
psql -U postgres -h localhost -d video_generator
```

#### Redis 连接失败

```bash
# 检查 Redis 服务是否运行
sudo systemctl status redis

# 测试连接
redis-cli ping
```

#### Celery 任务不执行

```bash
# 检查 Celery Worker 是否运行
ps aux | grep celery

# 查看 Celery 日志
tail -f logs/app.log
```

#### FFmpeg 不可用

```bash
# 检查 FFmpeg 是否安装
ffmpeg -version

# 安装 FFmpeg
sudo apt-get install ffmpeg  # Ubuntu/Debian
brew install ffmpeg          # macOS
```

### 10.2 日志查看

```bash
# 查看应用日志
tail -f logs/app.log

# 查看 Docker 日志
docker-compose logs -f api

# 查看 Celery 日志
docker-compose logs -f celery
```
