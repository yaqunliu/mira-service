# 音频生成设计文档

## 一、功能概述

本文档描述音频生成功能的设计与实现，包括：

1. **单个分镜音频生成**：为指定分镜生成旁白音频
2. **批量音频生成**：为创作下所有分镜生成音频
3. **音频合并**：将所有分镜音频合并为一个完整音频
4. **字幕生成**：自动生成 SRT 格式字幕文件

## 三、技术栈

### 3.1 Fish Audio TTS

系统使用 **Fish Audio** 作为文本转语音（TTS）服务：

- **API 客户端**：`app/utils/fish_audio.py`
- **支持格式**：MP3, WAV, PCM, OPUS
- **语速控制**：支持 0.5-2.0 倍速（映射到前端 0-10 范围）
- **超时重试**：60秒超时，最多重试3次

### 3.2 音频处理

使用 **pydub** 库进行音频处理：

- 音频时长计算
- 音频合并
- 格式转换

## 六、Celery 任务实现

### 6.1 任务模块

位置：`app/tasks/audio_task.py`

### 6.2 任务类型

| 任务名 | 说明 |
|--------|------|
| `generate_creation_audio_task` | 批量生成创作下所有分镜音频（主任务） |
| `generate_single_shot_audio_task` | 生成单个分镜音频 |
| `_generate_single_shot_audio` | 生成单个分镜音频（线程函数） |
| `_merge_audio_files` | 合并多个音频文件 |
| `_generate_and_upload_srt` | 生成并上传 SRT 字幕文件 |

### 6.3 批量生成流程

```python
@celery_app.task(bind=True, name="generate_creation_audio_task")
def generate_creation_audio_task(self, creation_id: int, voice_id: str, voice_speed: float = 1.0, force_regenerate: bool = False):
    """
    1. 验证创作是否存在
    2. 检查是否已生成音频（如果已存在且不强制重新生成，则跳过）
    3. 更新创作的 voice_id 和 voice_speed
    4. 查询所有场景和分镜
    5. 使用线程池并发生成所有分镜音频（最多3个并发）
    6. 合并所有音频
    7. 生成 SRT 字幕
    8. 更新创作状态为 AUDIO_GENERATED
    9. 返回结果
    """
```

### 6.4 单个分镜音频生成流程

```python
def _generate_single_shot_audio(shot_id: int, creation_id: int, voice_id: str, voice_speed: float = 1.0) -> dict:
    """
    1. 查询分镜信息
    2. 检查是否有旁白文本（没有则跳过）
    3. 调用 Fish Audio TTS：
       - 将 voice_speed (0-10) 映射到 Fish Audio speed (0.5-2.0)
       - speed = 0.5 + (voice_speed / 10.0) * 1.5
    4. 获取音频时长（使用 pydub）
    5. 保存到临时文件
    6. 上传到 US3
    7. 更新 Shot.audio_url 和 audio_duration
    8. 返回结果（包含 audio_bytes 用于后续合并）
    """
```

### 6.5 音频合并流程

```python
def _merge_audio_files(audio_results: List[Dict], creation_id: int) -> Optional[str]:
    """
    1. 按 (scene_id, shot_number) 排序音频结果
    2. 使用 pydub 合并所有音频：
       - 加载每个音频文件
       - 使用 AudioSegment + 操作符合并
    3. 导出合并后的音频（MP3格式，128k比特率）
    4. 上传到 US3
    5. 返回合并后的音频URL
    """
```

### 6.6 字幕生成流程

```python
def _generate_and_upload_srt(audio_results: List[Dict], creation_id: int) -> Optional[str]:
    """
    1. 按 (scene_id, shot_number) 排序音频结果
    2. 计算每个分镜的开始和结束时间：
       - 第一个分镜：start_time = 0, end_time = duration
       - 后续分镜：start_time = 前一个的 end_time, end_time = start_time + duration
    3. 生成 SRT 格式字幕内容：
       - 序号
       - 时间轴（HH:MM:SS,mmm --> HH:MM:SS,mmm）
       - 文本内容
       - 空行分隔
    4. 保存到临时文件
    5. 上传到 US3
    6. 返回字幕文件URL
    """
```

### 6.7 音频存储路径

```
单个分镜音频: creations/{creation_id}/shots/{shot_id}/audio_{uuid}.mp3
合并音频: creations/{creation_id}/merged_audio_{uuid}.mp3
字幕文件: creations/{creation_id}/subtitle_{uuid}.srt
```

### 6.8 语速映射规则

前端传入的 `voice_speed` 范围是 0-10，需要映射到 Fish Audio 的 speed 参数（范围 0.5-2.0）：

```python
# 线性映射公式
fish_speed = 0.5 + (voice_speed / 10.0) * 1.5

# 示例
voice_speed = 0  → fish_speed = 0.5  (最慢)
voice_speed = 5  → fish_speed = 1.25 (中等)
voice_speed = 10 → fish_speed = 2.0  (最快)
```

```srt

2

3
```

## 八、前端集成

### 8.1 批量生成流程

```typescript
// 1. 启动任务
const taskId = await startGenerateAudio(creationId, {
  voice_id: "54a5170264694bfc8e9ad98df7bd89c3",
  voice_speed: 1.0
});

// 2. 轮询进度
pollTaskProgress(taskId, {
  onProgress: (data) => {
    const progress = data.progress;
    // 更新进度条
    setProgress(progress.completed / progress.total);
    // 显示当前阶段
    if (progress.stage === "generating_audio") {
      showStatus(`正在生成音频: ${progress.completed}/${progress.total}`);
    } else if (progress.stage === "merging_audio") {
      showStatus("正在合并音频...");
    } else if (progress.stage === "generating_subtitle") {
      showStatus("正在生成字幕...");
    }
  },
  onComplete: (data) => {
    const resource = data.resource;
    // 更新创作音频和字幕URL
    updateCreationAudio(resource.audio_url);
    updateCreationSubtitle(resource.subtitle_url);
    showSuccess('音频生成完成');
  },
  onError: (error) => {
    showError(error);
  }
});
```

### 8.2 轮询建议

- **轮询间隔**：2-3 秒
- **超时处理**：建议设置最大轮询时间（如 30 分钟）
- **错误重试**：遇到网络错误时可适当重试

## 九、注意事项

1. **并发控制**：使用线程池，最多 3 个并发，避免过多请求导致 API 限流
2. **音频格式**：统一使用 MP3 格式，128k 比特率
3. **时长计算**：使用 pydub 计算音频时长，用于字幕时间轴
4. **排序规则**：音频合并和字幕生成都按 (scene_id, shot_number) 排序，确保顺序正确
5. **跳过处理**：没有旁白文本的分镜会自动跳过
6. **状态同步**：任务完成后会自动更新 `creation.status` 为 `AUDIO_GENERATED`
7. **临时文件清理**：所有临时文件在处理完成后都会自动清理

## 十二、错误处理

### 12.1 常见错误

| 错误类型 | 原因 | 处理方式 |
|---------|------|---------|
| 空音频 | TTS 返回空数据 | 重试，最多3次 |
| 超时 | TTS 请求超时 | 重试，最多3次 |
| 无旁白文本 | 分镜没有 narration | 跳过该分镜 |
| US3 上传失败 | 网络或权限问题 | 记录错误，任务失败 |

### 12.2 日志记录

所有错误都会记录详细日志，包括：
- 失败的分镜ID
- 错误信息
- 对应的文本内容（用于调试）
