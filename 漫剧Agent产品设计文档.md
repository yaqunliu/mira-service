# 漫剧 Agent 产品设计文档

> 版本: v1.0
> 日期: 2025-01-27

---

## 1. 设计理念

### 1.1 核心原则

```
对话是主线，看板是画布
```

- **对话驱动**：用户通过自然语言与 Agent 交互，下达指令、反馈意见
- **可视化呈现**：产出物（图片、视频、分镜）在看板上结构化展示
- **无缝衔接**：对话中的决策实时反映到看板，看板上的操作同步到对话

### 1.2 用户心智模型

```
用户 ←→ AI导演助手 ←→ 制作团队（后台Agent们）
         ↓
      可视化看板（作品展示）
```

用户感知上是在和一个"AI导演助手"对话，这个助手：
- 理解用户意图
- 协调后台各个专业 Agent 工作
- 在看板上展示阶段性成果
- 征求用户确认后继续

## 2. 整体布局

### 2.1 三栏式布局

```
┌─────────────────────────────────────────────────────────────────────────────┐
│  📽️ 漫剧工作室                                    [项目列表] [设置] [帮助]  │
├────────────────┬────────────────────────────────────┬───────────────────────┤
│                │                                    │                       │
│    侧边栏       │            主看板区                 │       对话区          │
│   (导航/资产)   │        (可视化展示)                 │    (Agent交互)        │
│                │                                    │                       │
│   200px        │            flex                    │       400px           │
│                │                                    │                       │
└────────────────┴────────────────────────────────────┴───────────────────────┘
```

### 2.2 响应式适配

```
桌面端 (>1400px):  侧边栏 + 看板 + 对话框（三栏并列）
平板端 (768-1400px): 看板 + 对话框（侧边栏收起为图标）
移动端 (<768px):   底部Tab切换（对话/看板/资产）
```

### 6.2 联动实现机制

```typescript
// 前端状态管理
interface AppState {
  // 对话状态
  conversation: Message[];

  // 看板状态
  activeView: 'script' | 'characters' | 'scenes' | 'storyboards' | 'timeline' | 'preview';
  highlightedAsset: string | null;

  // 联动队列
  pendingActions: Action[];
}

// Agent 消息中携带看板指令
interface AgentMessage {
  text: string;
  boardActions?: BoardAction[];
}

interface BoardAction {
  type: 'switchView' | 'highlight' | 'scroll' | 'update';
  target: string;
  data?: any;
}

// 示例：Agent 返回的消息
{
  text: "请在看板上确认角色形象",
  boardActions: [
    { type: 'switchView', target: 'characters' },
    { type: 'highlight', target: 'character_xiaoming' },
    { type: 'scroll', target: 'character_xiaoming' }
  ]
}
```

```typescript

interface ServerMessage {
  type: 'chat' | 'progress' | 'board_action' | 'notification';
  payload: any;

interface ChatMessage {
  type: 'chat';
  payload: {
    role: 'agent' | 'system';
    content: string;
    actions?: ActionButton[];
    boardActions?: BoardAction[];
    attachments?: Attachment[];
  };
}

// 进度更新
interface ProgressMessage {
  type: 'progress';
  payload: {
    stage: string;
    current: number;
    total: number;
    details: ProgressItem[];
  };
}

// 看板操作
interface BoardActionMessage {
  type: 'board_action';
  payload: {
    action: 'switchView' | 'highlight' | 'update' | 'scroll';
    target: string;
    data?: any;
  };
}

// 客户端 → 服务端
interface ClientMessage {
  type: 'user_message' | 'user_action' | 'board_operation';
  payload: any;
}
```

## 11. 附录

### 11.1 设计原则清单

| 原则 | 说明 |
|-----|------|
| 对话优先 | 主要交互通过对话完成，降低学习成本 |
| 渐进披露 | 复杂功能在需要时才展示 |
| 即时反馈 | 每个操作都有视觉反馈 |
| 可恢复 | 任何操作都可撤销或重做 |
| 透明进度 | 清晰展示当前阶段和预计时间 |
| 灵活控制 | 支持全自动到全手动的各种模式 |

### 11.2 快捷键

| 快捷键 | 功能 |
|-------|------|
| `Ctrl/Cmd + Enter` | 发送消息 |
